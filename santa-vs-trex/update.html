One-time setup: GitHub key

This page saves to your GitHub site, so it needs a key from your GitHub account. You only do this once per phone.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it "Rematch Fund". Set the expiration to the end of January.
  3. Under Repository access, choose Only select repositories and pick friday-fun-night.
  4. Under Permissions, set Contents to Read and write.
  5. Press Generate, copy the key, and paste it here.
